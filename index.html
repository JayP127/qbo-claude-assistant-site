Benemetry QuickBooks assistant

This is the information site for an internal tool of Benemetry Ltd. The tool connects Benemetry's own QuickBooks Online company to Claude, the AI assistant made by Anthropic, so that authorised Benemetry staff can ask questions about the company's books and, where enabled, record transactions with approval for each one. In the Intuit developer portal the tool is registered as the app Claude assistant.

  • Internal only. It is used by Benemetry Ltd staff for Benemetry's own accounts. It is not offered to the public, not listed on the Intuit App Store and not distributed.
  • Runs locally. The software runs on the staff member's own computer in the United Kingdom. This site hosts nothing but these pages: it holds no data and runs no code.
  • Open source underneath. It is built on Intuit's open-source QuickBooks Online MCP server, configured by Benemetry so that it can read, can create records only with a person's approval, and cannot change or delete anything.

  • Disconnect: how to revoke the tool's access.
