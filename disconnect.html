Disconnect the assistant

If Intuit sent you here, the Benemetry QuickBooks assistant ("Claude assistant") has just been disconnected from a QuickBooks Online company, and Intuit has stopped honouring its credentials. This page explains what that means and what remains to be done on the computer that ran the tool.

How to disconnect

  1. Sign in to QuickBooks Online as an administrator of the company.
  2. Open Apps, then My apps, find Claude assistant and choose Disconnect. Menu names may change slightly as Intuit updates QuickBooks.
  3. From that moment Intuit refuses the tool's access and refresh tokens. No data can be read or written through it.

Clean up the computer

  1. Delete the credential file ~/.qbo/production.env, and ~/.qbo/sandbox.env if a sandbox company was also connected. The tokens in them are already useless, but Benemetry's rule is that they do not linger.
  2. Remove the tool from the Claude applications: in a terminal in Benemetry's QuickBooks project folder run claude mcp remove quickbooks and claude mcp remove quickbooks-sandbox, and delete the quickbooks-readonly entry from the Claude Desktop configuration file if it exists.

What disconnecting does not do

  • It does not change or delete anything in QuickBooks Online. Records the tool created with your approval remain in the books.
  • It does not delete reports already saved in Benemetry's private repository, or data already in past Claude conversations. Those are handled under the privacy policy.
  • It does not notify this site. These pages hold no data and run no code, so there is nothing here to clear.

To connect again later, see Connect or reconnect.
